# Wireframes and layout contracts

These are structural low-fidelity references, not replacements for the rendered desktop/mobile mock-ups.

## Global shell — desktop
Brand/workspace switcher and global search in the top bar; status/profile controls on the right; persistent global sidebar; breadcrumbs, page title and primary action above page-specific content. The sidebar contains overview, projects, AI assistant, templates, activity, settings and project context.

## Workspace overview
Welcome plus an AI engineering prompt; recent projects; review queue/active runs; revision state and next safe actions; recent activity and conversations.

## Project creation
Step 1: objective. Step 2: review brief. Step 3: create project. Inputs include name, domain, units, objective and optional source files. Review scope, assumptions, missing inputs, success criteria and proposed artifacts before explicit confirmation.

## AI-native chat
Three panes on desktop: thread history; conversation messages including user, assistant and tool states; context and source panel. Include search threads, new chat, citation/evidence links, composer, attachments, explicit source attach/detach and permission-aware next actions.

## Engineering workbench
Three panes: project/artifact explorer; CAD, FEA, P&ID or calculation viewport; inspector/evidence panel with inputs, units, legend, validation and logs. The workflow strip stays visible: Geometry → Setup → Solve → Review → Approve.

## Mobile adaptation
Collapse the persistent sidebar into an accessible drawer; chat history and context become accessible sheets/tabs; wide tables become row cards or controlled horizontal scrolling; viewer toolbars remain reachable; never rely on hover alone; keep primary actions reachable without covering content.
