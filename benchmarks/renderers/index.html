Run discipline

  • Use the same browser, device, viewport, power mode, workload and warm/cold sequence for both engines.
  • Run at least five paired trials per workload. Close other GPU-heavy tabs and record device/OS/browser/GPU.
  • Renderer import/initialization and first render are timed separately from the steady-state frame sample.
  • This harness tests repeated box instances, orbit, visibility toggles and centre picking. It does not test STEP import, OCCT tessellation, stable BREP topology mapping or production memory limits.
  • Do not choose a production engine from one browser run. Record raw JSON and the device matrix with the decision.

Experimental benchmark. It does not prove CAD correctness, engineering validation, mobile stability on untested devices or production suitability.
